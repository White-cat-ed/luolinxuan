KDD2026

KDD 2026 · CCF-A · 韩国济州岛

OpenAqua: A Large-Scale Fine-Grained Dataset and Benchmark for Open Underwater Visual Perception

骆霖轩、穆攀*、白琮

第一作者 · 数据集与基准负责人

论文主页 PDF 项目与代码 数据集

一句话简介：建立五级生物分类体系与开放水下视觉基准，包含 77,970 张图像、16,540 个物种和 132,885 个细粒度实例。

展开摘要

水生生物多样性监测对于维持全球生态平衡至关重要。尽管计算机视觉的发展推动了水下感知研究，现有数据集大多局限于粗粒度类别，或缺少空间定位标注，严重限制了模型在真实场景中的细粒度生物识别能力。为弥补这一空白，我们提出 OpenAqua——首个面向开放水下视觉任务的大规模细粒度数据集。OpenAqua 采用五级生物分类体系，包含 77,970 张高质量图像，覆盖 16,540 个水生物种，并提供 132,885 个细粒度边界框及对应实例分割掩码。在此基础上，我们构建了覆盖标准目标检测、实例分割和水下开放词汇目标检测的综合基准。实验显示，随着识别粒度由粗到细，现有模型的性能显著下降，凸显了退化水下环境中细粒度语义感知与域适应的挑战。

ACM MMOral · 2025

ACM MM 2025 · CCF-A · Oral · 2284–2293 页

Physics-Coupled Frequency Dynamic Adaptation Network for Domain Generalized Underwater Object Detection

骆霖轩、穆攀*、白琮

第一作者

论文主页 PDF 代码

一句话简介：将水下成像物理先验与多频动态适配相结合，提升检测器的跨水域鲁棒性。

展开摘要

多样化环境带来的域偏移以及水下图像的严重退化仍然制约着水下目标检测。为此，我们提出 Hy-UOD：一个由超网络驱动、协同融合物理先验与多频特征学习的域泛化框架。该方法通过基于元学习的超网络编码环境相关物理描述符并生成跨域泛化参数，再以多频特征动态适配模块通过低频校正、高频细化和中频重建补偿退化特征。多个水下数据集上的实验表明，该方法具有稳健的检测性能和较强的跨域泛化能力。

ICASSP2025

ICASSP 2025 · CCF-B · 印度海得拉巴 · 1–5 页

Prompt-UIE: A Unified Prompt-Driven Framework for Underwater Image Enhancement

张艳玲、骆霖轩、穆攀*、白琮

第二作者

论文主页 PDF 代码

一句话简介：利用视觉 Prompt 与物理引导损失，使统一增强模型以 0.88M 可训练参数适应多样水下退化。

展开摘要

复杂多样的水下环境会造成多种图像退化，而现有方法大多聚焦于单一数据集，限制了模型对不同退化特征的探索。Prompt-UIE 无需同时使用多个数据集，即可将预训练特定任务模型适配到不同水下条件。该方法结合基于背景光的视觉 Prompt 模块和反向透射图引导损失：视觉 Prompt 引导模型针对不同水体类型执行增强，物理引导损失则提升其处理空间非均匀退化的能力。全参考与无参考数据集上的实验验证了该方法的有效性和鲁棒性。

硕士研究主线

我的硕士研究围绕一个连贯目标展开：通用开放水下感知。我将其分解为环境开放与类别开放两条主线，逐级解决关键问题，并进一步探索环境与类别的统一建模。

主线一 · 环境开放

基础稳健感知 → 域泛化 → 通用泛化

Prompt-UIE 与 WCPM → Hy-UOD → Hy-GUOD

主线二 · 类别开放

细粒度类别体系 → 开放词汇感知

OpenAqua 数据集与综合基准

阶段五 · 双线汇合：以物理—语义世界模型和多模态 Agent 推理，统一建模环境开放与类别开放。

01

基础稳健感知 · 2024–2025

Prompt-UIE 与 WCPM

从轻量视觉 Prompt 跨水域增强出发，进一步通过频率—尺度耦合学习构建面向检测任务的轻量水下特征。

Prompt-UIE 仅需 0.88M 可训练参数；WCPM 在 DUO 上达到 69.9 AP，模型规模为 9.854M。

02

物理引导域泛化 · 2024–2025

Hy-UOD

以背景光和透射图表征水域光学状态，通过超网络与多频动态适配生成随水体条件变化的检测参数。

第一作者发表于 ACM MM 2025 Oral。

03

通用域泛化 · 2025–至今

Hy-GUOD

面向稀疏单源监督，通过物理一致域演化、光学状态逆估计、检测器动态调制和冲突感知双层优化提升未知环境泛化能力。

第一作者论文待投。

04

细粒度开放基准 · 2025–2026

OpenAqua

围绕五级生物分类体系，建立目标检测、实例分割和开放词汇检测协议，面向真实水生生物多样性感知。

77,970 张图像 · 16,540 个物种 · 132,885 个实例；第一作者发表于 KDD 2026。

05

环境—类别统一建模 · 在研

通用开放水下多模态智能体

探索同时表征光学状态与层级类别知识的物理—语义世界模型，通过 Agent 推理应对未知水体与未知目标同时出现的开放场景。

方法基础：物理引导学习、域泛化、开放词汇检测、频域建模、视觉 Prompt、超网络与元学习。

实验工具：PyTorch、MMDetection、Ultralytics、SAM 2，以及多数据集对比、消融、跨域评测与 Benchmark 构建。
