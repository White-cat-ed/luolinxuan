关于我

OpenAqua: A Large-Scale Fine-Grained Dataset and Benchmark for Open Underwater Visual Perception

骆霖轩、穆攀*、白琮

第一作者 · 数据集与基准负责人

录用公告 项目与代码 数据集 论文 / PDF 即将公开 DOI 10.1145/3770855.3817535 等待公开解析

一句话简介：建立五级生物分类体系与开放水下视觉基准，包含 77,970 张图像、16,540 个物种和 132,885 个细粒度实例。

展开摘要

水生生物多样性监测对于维持全球生态平衡至关重要。尽管计算机视觉的发展推动了水下感知研究，现有数据集大多局限于粗粒度类别，或缺少空间定位标注，严重限制了模型在真实场景中的细粒度生物识别能力。为弥补这一空白，我们提出 OpenAqua——首个面向开放水下视觉任务的大规模细粒度数据集。OpenAqua 采用五级生物分类体系，包含 77,970 张高质量图像，覆盖 16,540 个水生物种，并提供 132,885 个细粒度边界框及对应实例分割掩码。在此基础上，我们构建了覆盖标准目标检测、实例分割和水下开放词汇目标检测的综合基准。大量实验表明，随着识别粒度由粗到细，现有模型的性能显著下降，凸显了退化水下环境中细粒度语义感知与域适应的挑战。我们相信，OpenAqua 将推动细粒度水下视觉、长尾分布学习和水生生态系统监测的发展。

Hy-GUOD: A Physics-Guided Hypernetwork Framework for Domain Generalized Underwater Object Detection

骆霖轩 等

第一作者

稿件可邮件索取 代码即将公开

一句话简介：以物理光学状态刻画水下域偏移，并利用超网络动态调整检测器，以适应未知水域环境。

展开摘要

复杂光学变化会导致水下目标检测模型的性能严重下降；当训练数据仅来自有限源域时，这类域偏移尤其难以处理。现有水下目标检测方法主要依赖图像恢复或静态结构先验，而域泛化方法通常将域偏移视为一般的数据分布差异，因此难以表示由光学因素驱动的水下域变化，也难以将退化线索与任务相关语义解耦。为解决这些问题，我们提出 Hy-GUOD——一个面向广义水下目标检测的物理引导超网络框架。Hy-GUOD 使用物理光学状态显式参数化水下域偏移，并学习利用这些状态实现鲁棒检测。具体而言，基于超网络的光学状态感知机制通过逆向估计，从退化观测中解耦光学先验，再将其转化为检测器动态特征响应的域自适应引导。为协调物理感知与目标检测，我们进一步提出 Navi-Gate 和双层优化策略，在源域受限监督下调节任务梯度交互。四个水下基准和一个陆地雾天基准上的大量实验验证了 Hy-GUOD 的有效性与通用性，并显示其在单源、多源、跨数据集、标准域内以及雾天目标检测协议下均保持稳定优势。

Physics-Coupled Frequency Dynamic Adaptation Network for Domain Generalized Underwater Object Detection

骆霖轩、穆攀、白琮

第一作者

论文主页 PDF 代码

一句话简介：将水下成像物理先验与多频动态适配相结合，提升检测器的跨水域鲁棒性。

展开摘要

尽管水下目标检测技术不断发展，多样化环境带来的域偏移以及水下图像的严重退化仍然制约着模型性能。为解决这些问题，我们提出 Hy-UOD：一个由超网络驱动、协同融合物理先验与多频特征学习的域泛化框架。为缓解域偏移，我们设计了基于元学习的超网络架构，通过编码环境相关的物理描述符生成跨域泛化参数。为进一步降低复杂退化对检测性能的影响，我们基于超网络特征和域相关信息设计了多频特征动态适配模块，通过“低频校正、高频细化和中频重建”对退化特征进行系统补偿。多个水下数据集上的实验表明，该方法具有稳健的检测性能和较强的跨域泛化能力。

Prompt-UIE: A Unified Prompt-Driven Framework for Underwater Image Enhancement

张艳玲†、骆霖轩†、穆攀、白琮

共同第一作者

论文主页 PDF 代码

一句话简介：利用视觉 Prompt 与物理引导损失，使统一增强模型以 0.88M 可训练参数适应多样水下退化。

展开摘要

复杂多样的水下环境会造成多种类型的图像退化，但现有方法大多聚焦于单一水下数据集，退化模式的相似性限制了模型对不同退化特征的探索。为此，我们提出基于 Prompt 学习的统一水下图像增强模型 Prompt-UIE，重点挖掘水下图像的共同属性。Prompt-UIE 无需同时使用多个数据集，即可将预训练的特定任务模型适配到不同水下条件。该方法在基础模型上集成视觉 Prompt 模块和反向透射图引导损失：基于背景光的视觉 Prompt 通过精心设计的策略，引导模型针对不同水体类型执行增强；反向透射图引导损失则提升模型处理空间非均匀退化的能力。全参考与无参考数据集上的实验验证了该方法的有效性和鲁棒性。

一种基于光流对齐的交叉模式神经网络的裂缝检测方法

骆霖轩、韩晓东、黄嘉浩、吴欢娱、王嘉萁、陈采吟

第一发明人 · 专利权人：闽江学院

专利主页 授权文本 PDF

展开摘要

本发明提出一种基于光流对齐的交叉模式神经网络的裂缝检测方法。该方法基于光流对齐的交叉模式语义分割神经网络 FAC-Net，通过融合 RGB 图像和深度图像特征信息进行跨模态裂缝检测：首先构建数据集并训练 FAC-Net；随后获取待检测目标的 RGB 图像与深度图像；最后将同一目标的 RGB 与深度图像输入预训练网络，得到包含裂缝语义像素和背景语义像素的分类结果图像，从而实现融合 RGB 与深度信息的跨模态裂缝检测。

一种基于跨模态对齐融合的 RGB-D 语义分割方法

李佐勇、骆霖轩、刘伟霞、赖桃桃

发明人 · 申请人：闽江学院

专利主页 公开文本 PDF

展开摘要

本发明涉及一种基于跨模态对齐融合的 RGB-D 语义分割方法。该方法使用空间通道注意力机制，充分利用空间和通道关系，使两个分支均能关注来自另一模态的互补信息，以缓解多模态引入的噪声；同时引入语义流矫正模块，解决不同模态对应像素难以良好对齐的问题；在解码器部分同样加入语义流矫正模块，使深层语义信息能够更有效地传递到浅层。实验验证了所提出算法的可靠性与可行性。
